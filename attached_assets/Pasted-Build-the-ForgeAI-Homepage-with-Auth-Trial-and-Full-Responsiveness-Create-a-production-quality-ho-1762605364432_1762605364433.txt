Build the ForgeAI Homepage with Auth, Trial, and Full Responsiveness

Create a production-quality homepage in React + Tailwind that matches the existing dashboard style. Include a working Login/Sign up modal with Google OAuth and Email + Password flows. The page must be fully responsive for mobile, tablet, and desktop.

Auth provider: Supabase Auth (recommended) with Google provider enabled

Env vars: VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY

Alternative acceptable: Firebase Auth with Google provider. If using Firebase, expose VITE_FIREBASE_* config and implement equivalent flows.

Auth requirements

Use Supabase Auth or Firebase Auth. Supabase preferred for speed.

Common requirements

Modal-based Login and Sign up with tabs

Providers

Google OAuth button

Email + Password form

Forgot Password

Email input to send reset link

Confirmation state in UI

Validation and UX

Disable submit while loading

Inline errors from provider

Success states and toasts

Routing rules

If user clicks Start Free Trial or presses Simulate while not authenticated

open auth modal

After successful auth

if the user came from Trial → push to /dashboard/create with prefilled query params

else push to /dashboard

State management

Store auth session in provider SDK

On app mount, restore session and update UI buttons

Show avatar menu when logged in with menu items: Dashboard, API Keys, Sign out

Backend hook

For protected API calls, send the Supabase JWT in Authorization: Bearer <token>

Provide a helper to get the token from the client and attach it to requests

Responsiveness

Mobile first. Test breakpoints at 360, 768, 1024, 1280.

Navbar collapses to a hamburger.

Hero stacks vertically on mobile.

Cards become a single column on small screens, two columns on tablets, three on desktop.

Buttons and inputs have comfortable touch targets.

Components to deliver

HomePage.jsx composing: Navbar, Hero, Why, Comparison, Trial, Testimonials, Footer

AuthModal.jsx with tabs: Login, Sign up, Forgot password

Buttons: Continue with Google, Email login, Email sign up

TrialForm.jsx with three inputs and simulate button

Emits prefill data and triggers auth modal when unauthenticated

MarkdownPreview.jsx using react-markdown + remark-gfm

useAuth.ts(x) or authClient.ts for Supabase client and session helpers

routes update to wire Get Started and post-auth redirects

Acceptance criteria

Login, Sign up, Google OAuth, and Forgot Password all work end to end

Auth modal opens from Navbar buttons and Trial section when needed

After login from modal, user is redirected correctly

Trial form prefills the Create Persona page when authenticated

Page renders correctly on mobile, tablet, and desktop

Markdown preview renders bold, lists, code blocks in the Trial preview

Color palette and spacing match the dashboard look and feel
